# 验证协议

先写主张，再选能证伪它的验证。阈值来自题目精度、数据噪声、数值误差或决策容忍度；没有依据时报告连续结果，不捏造统一通过线。

## 通用最低检查

- 变量、单位、索引、边界和符号与问题契约一致。
- 硬约束逐条复算；可行不等于最优。
- 用解析特例、小规模穷举、独立实现或已知基准检查核心逻辑。
- 记录停止状态、随机种子、预算、失败运行和近似参数。
- 结论变化时，追溯是数据、模型、算法、参数还是实现导致。

## 按模型选择证据

### 优化和图算法

- 检查每条约束、守恒、路径/流合法性和目标函数重算。
- 精确方法报告求解状态、上下界和 gap；近似方法核对保证条件；启发式报告预算、多种子分布和强基线。
- 用缩小实例穷举或独立求解器交叉验证。复杂度包含状态数、标签数、前沿规模、场景数等隐含参数。
- 扰动约束和成本时解释结构变化，不机械要求每个指标同向变化。

### 预测、回归和机器学习

- 划分尊重时间、群组、空间、重复测量和部署边界；预处理只在训练部分拟合。
- 与朴素、季节性或简单可解释基线同口径比较。
- 依据输出检查残差结构、校准、区间覆盖、类别代价或排名指标；不把正态性作为所有模型的通用门槛。
- 评估外推范围、分布漂移和特征可获得性。

### ODE/PDE和机理模型

- 检查量纲、符号、守恒、初始/边界条件和极限情形。
- 参数标定前检查结构与实践可识别性；报告参数相关和不确定性。
- 做步长/网格收敛和稳定性检查；用解析特例或高精度解对照。
- 区分“数值程序解对了方程”和“方程代表了现实”。

### 仿真和随机模型

- 验证事件顺序、状态不变量、随机数使用和退化情形。
- 说明预热、重复次数和 Monte Carlo 误差；根据精度决定样本量。
- 用简化场景与解析或枚举结果对照；改变随机种子只检验算法稳定性，不等于模型有效。

### 综合评价与多目标

- 检查成本/效益方向、标准化分母、零值、量纲和指标冗余。
- 权重来源与一致性单独说明；做权重区间、排名切换和替代标准化敏感性。
- 区分精确支配与近似覆盖；近似覆盖不具有精确支配的反对称性。
- 评价候选集时同时考虑合法性、规模、覆盖/距离、结构多样性和计算资源。

### 因果主张

- 明确处理、结果、目标人群、时间和 estimand。
- 列出识别假设及其可检验含义；检查平行趋势、工具变量有效性、重叠或混杂敏感性。
- 无法支持识别时，把结论降级为关联或预测，不用模型复杂度伪装因果。

## 敏感性和鲁棒性

先识别不确定性来源：参数、样本、测量、情景、结构或求解随机性。扰动范围应来自置信区间、业务范围、题设范围或数值精度。重点报告结论或决策何时翻转，而不只是“变化不大”。

## 失败处理

验证失败时先判断：

1. 输入和单位是否错误；
2. 实现和索引是否错误；
3. 数值尺度、收敛或停止条件是否错误；
4. 模型假设和识别是否错误；
5. 评价指标和对照是否错误。

不要用更多图表掩盖失败。修复后只重跑受影响部分，并保留失败原因和边界结论。
