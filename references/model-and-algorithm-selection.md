# 模型与算法选择

本参考用于候选模型和算法不明显时。它提供判别问题，不提供按题型字母套用的答案。

## 先识别数学结构

| 结构 | 关键问题 | 候选模型方向 | 算法选择重点 |
|---|---|---|---|
| 确定性优化 | 变量连续/整数？目标与约束线性、凸、可分吗？ | LP/QP/MILP/MINLP、网络流、动态规划 | 先利用凸性、全酉模、网络结构；报告状态、界和 gap |
| 组合与路径 | 单路径还是解集？单目标、多目标、资源约束？ | 最短路、流、匹配、VRP、资源约束路径、Pareto路径 | 规模、标签数、前沿大小、精确/近似保证；小图真值 |
| 多目标决策 | 要完整前沿、代表集还是偏好下的单解？ | ε-约束、目标规划、Pareto搜索、偏好排序 | 不要过早加权；检查支配、尺度、近似覆盖和偏好敏感性 |
| 不确定优化 | 随机量有分布、区间还是场景？ | 随机规划、鲁棒优化、机会约束、CVaR | 区分风险态度；做样本外场景和保守度比较 |
| 预测 | 时间、主体、空间或群组依赖是什么？ | 可解释基线、回归/树模型、时序/状态空间、层级模型 | 划分必须尊重依赖；先基线，再按残差结构升级 |
| 分类/聚类 | 标签可信？类别失衡？距离是否有意义？ | 规则/逻辑回归/树/SVM；层次/密度/混合模型 | 指标与任务损失一致；聚类需稳定性和外部解释 |
| 机理演化 | 守恒、流量、反馈、时滞和边界是什么？ | 代数方程、ODE/PDE、差分、状态空间、离散事件 | 量纲、初边值、可识别性、离散收敛和稳定性 |
| 仿真 | 随机过程、事件和策略如何作用？ | Monte Carlo、离散事件、Agent-based | 分开验证程序与模型；预热、重复、方差和随机种子 |
| 综合评价 | 排名是决策目标还是中间输入？ | 标准化加权、TOPSIS、AHP辅助定权、Pareto/支配分析 | 指标方向、冗余、尺度、权重依据、排名反转和敏感性 |
| 因果问题 | 题目要预测还是干预效应？ | 随机实验、DID、IV、匹配、因果图 | 明确 estimand 和识别假设；条件不足只能报告关联 |

## 候选淘汰顺序

1. **合法性：** 输出是否对应题目，所有硬约束能否表达。
2. **可识别性：** 参数或因果效应能否由现有数据区分。
3. **数据边界：** 是否使用未来信息、测试集、重复主体或不可获得数据。
4. **计算可行性：** 根据实际规模估计状态、变量、标签、场景或网格数量。
5. **正确性证据：** 能否得到最优界、误差界、收敛证据或可靠经验对照。
6. **任务表现与稳健性：** 在冻结的同口径评价下比较。
7. **简约和解释：** 若表现与风险相近，选择更易解释和复算者。

前四项是硬门槛，不能被“创新性”或平均分抵消。

## 基线的作用

基线不是陪衬，应当足够简单、合法且可复算，并与候选共享同一数据边界、约束边界和评价口径。复杂模型只有在以下至少一项有证据时才升级：

- 基线出现系统残差或结构失配；
- 基线无法表达关键硬约束或机制；
- 不确定性会实质改变决策；
- 复杂模型带来可重复且与题目相关的提升；
- 需要基线不能提供的保证或输出。

## 算法保证用语

| 证据 | 可以说 | 不可以说 |
|---|---|---|
| 精确算法正常结束且证书有效 | 全局最优/完整前沿 | 仅凭“用了某算法”声称最优 |
| 有上下界或 optimality gap | 在给定 gap 内最优 | 把可行解当最优解 |
| 已证明的近似比/覆盖因子 | 满足所述条件下的近似保证 | 忽略条件或让误差重复累积 |
| 多起点启发式稳定 | 在给定预算与种子下表现稳定 | 全局最优 |
| 交叉验证/回测 | 在对应划分与样本上的泛化证据 | 对未来、地区或机制无限外推 |

## 停止规则

只做能改变模型选择、参数解释、风险判断或结论可信度的额外实验。若两个候选的差异可以由一个小探针判定，先做探针；若无法区分且结论相同，优先简单者并披露结构不确定性。
